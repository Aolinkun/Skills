# 教学模式参考

## 1. 选择原则

根据目标、先备知识、错误类型和时间约束选择方式。不要把偏好标签当作固定学习风格。

一个单元只解决一个主要认知缺口。优先安排能产生可观察行为的活动：预测、解释、比较、补全、找错、迁移或真实产出。

## 2. 按基础选择

### 零基础

`最小完整示范 → 点明关键关系 → 部分补全 → 独立变式`

- 使用具体例子建立第一个锚点；
- 不要求凭空推导术语；
- 每次减少一点支架。

### 有一定基础

`先回忆 → 找最小漏洞 → 针对解释 → 反例辨析 → 新场景`

- 跳过稳定内容；
- 只解释错误附近；
- 用新题验证，不重复原题。

### 熟练者

`复杂案例 → 比较方案 → 追问假设与代价 → 远迁移或创造`

- 加入不完整信息和冲突约束；
- 要求说明证据、边界与取舍；
- 让学习者批判或改进现有方案。

## 3. 按任务类型选择

### 概念理解

`具体案例 → 初步判断 → 提炼关系 → 正反例 → 相近概念 → 新场景`

### 程序与技能

`完整示范 → 关键决策 → 部分补全 → 独立完成 → 修改错误 → 真实任务`

技能型主题优先评估产出。只会解释但做不出来不算通过。

### 考试准备

`范围与题型 → 知识地图 → 起点题 → 错因分类 → 间隔复习 → 模拟测试`

把错因区分为知识缺失、概念混淆、审题、程序错误、记忆失败和时间分配。

### 决策与应用

`目标 → 事实/判断分离 → 约束与激励 → 多假设 → 区分证据 → 最小行动 → 复盘`

不要只给一个漂亮框架或未经验证的“本质”。

### 创造产出

`分析样例 → 建立评价标准 → 有约束模仿 → 独立产出 → 按证据修订 → 新题迁移`

## 4. 检测任务设计

从低到高选择：回忆、解释、辨析、应用、分析、评估、创造。

要求：

- 每题对应一个目标；
- 题面不泄露关键答案；
- 迁移题改变表面情境但保留底层结构；
- 一道综合题证据足够时不凑题数；
- 开放题预先明确关键标准和不可接受错误。

## 5. 学科提示

- **哲学与人文**：从文本、主张冲突和历史语境进入，避免标签化。
- **数学与逻辑**：先直觉再形式化，要求中间步骤和自构反例。
- **编程与技术**：最小可运行示例、预测输出、运行验证、解释错误、独立实现。
- **历史与社会科学**：区分事实、解释和价值判断，比较证据强弱与多重因果。
- **商业与管理**：落到目标、变量、激励、约束、指标和行动，防止事后归因。
- **写作与表达**：先定义受众和效果，再以真实产出及修改证据评估。

## 6. 节奏控制

- 连续两个高负荷任务后安排短总结或简单回忆。
- 连续两次失败时只降低一个难度变量。
- 表现强时减少讲解，增加边界、证据和迁移。
- 明显疲劳时记录恢复点，不用更多题惩罚疲劳。
