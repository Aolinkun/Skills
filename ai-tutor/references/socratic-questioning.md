# 苏格拉底追问参考

## 1. 适用边界

只在学习者已有最小知识锚点时使用追问。目标是暴露假设、关系和边界，不是让零基础者猜答案。

优先追问：

- 学习者能说出部分概念，但表达含糊；
- 答案里存在未经说明的假设；
- 术语正确，但不能解释原因或应用；
- 需要区分相近概念、条件或反例。

先示范而不是追问：

- 完全零基础；
- 纯操作步骤、语法或快捷键；
- 高风险或紧急信息；
- 连续受挫、无法形成任何起点。

## 2. 从回答生成下一问

1. 找出答案中最影响结论的一句话。
2. 标记它属于事实、概念关系、条件、推断还是模糊占位。
3. 只选择一个最有信息量的缺口。
4. 用新问题改变一个条件或要求一个边界。
5. 根据新回答决定解释、继续追问或进入迁移。

优先句式：

- “如果只改变这个条件，结论会怎样？”
- “X 和 Y 的本质差异是什么？”
- “什么情况下这个说法不成立？”
- “你这一步依赖了哪个假设？”
- “有什么证据会让你改变判断？”

## 3. 追问质量标准

高质量问题应满足：

- 对应一个明确目标；
- 来自学习者刚才的真实回答；
- 不在题面泄露核心答案；
- 能区分背诵、理解和应用；
- 回答后能改变下一步教学决策。

不要为了“像苏格拉底”持续反问。若一个直接解释比追问更高效，先解释，再检测。

## 4. 常见破绽与追问

| 回答特征 | 可能问题 | 追问方向 |
|---|---|---|
| 使用“都、一定、任何” | 过度概括 | 要求反例或适用条件 |
| 使用“差不多、那种感觉” | 关系未说清 | 要求具体变量或因果 |
| 背出定义 | 可能只记术语 | 换表面情境应用 |
| 给出结论无理由 | 推理缺口 | 要求中间步骤或证据 |
| 只会熟悉案例 | 迁移不足 | 改变行业、角色或约束 |
| 过度谨慎 | 不敢形成判断 | 给定条件后要求暂定结论 |

“可能、通常、在某条件下”本身不是模糊。只有无法说明条件、机制或证据时才要求具体化。

## 5. 反例与极端情况

按以下顺序使用：

1. 边界案例：刚好接近概念边界。
2. 反例：表面符合但核心不成立。
3. 极端情况：把变量推到极限，暴露隐含假设。
4. 反事实：改变一个条件，检查因果理解。

一次只改变一个主要变量，避免学习者不知道哪项变化导致结果变化。

## 6. 对话纪律

- 不说“这题很简单”或“下面更难”。
- 不把复合问题伪装成一个问题。
- 不用“你明白了吗？”替代输出检测。
- 不在学习者回答前评价人格、聪明程度或学习能力。
- 评估后明确指出答对、答漏和下一步，不用空泛表扬掩盖缺口。
