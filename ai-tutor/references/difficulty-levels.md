# 认知活动与任务难度参考

## 1. 分开记录两个维度

不要把 Bloom 认知活动直接等同于难度。

| 认知活动 | 可观察行为 | 示例 |
|---|---|---|
| 记忆 | 回忆事实、术语、步骤 | 不看材料说定义 |
| 理解 | 解释关系、概括、举例 | 用自己的话说明原因 |
| 应用 | 在情境中使用 | 用概念解决新案例 |
| 分析 | 拆解、比较、找因果 | 区分变量和假设 |
| 评估 | 按标准判断证据或方案 | 比较局限和代价 |
| 创造 | 综合形成新产出 | 设计模型、方案或作品 |

任务难度使用 1—5：

| 难度 | 特征 |
|---|---|
| 1 | 单一概念、熟悉情境、明确提示、短输出 |
| 2 | 少量概念、近迁移、轻提示 |
| 3 | 多步骤、部分新情境、需要解释理由 |
| 4 | 多概念整合、干扰信息、远迁移、高精度 |
| 5 | 信息不完整、约束冲突、开放权衡或创造 |

“创造一个简单例子”可能认知活动高但任务难度低；“准确记住复杂规则”可能只是记忆但难度很高。

## 2. 一次只调一个主要变量

- 概念数量；
- 步骤长度；
- 提示级别；
- 情境熟悉度；
- 情境变化程度；
- 干扰信息；
- 时间限制；
- 输出精度；
- 证据要求；
- 认知活动。

同时改变多个变量会让表现变化无法解释。

## 3. 调整规则

### 表现强

- 减少一级提示，或增加一个新情境；
- 从近迁移转向远迁移；
- 要求说明边界、反例、证据或假设；
- 跳过已稳定且低价值的重复练习。

不要机械“连续答对就跳两级”。

### 部分掌握

- 保持核心难度，只改变呈现方式；
- 只定位一个缺口：定义、关系、条件、步骤或应用；
- 用新题验证。

### 明显卡住

- 回到缺失的先备知识；
- 减少概念数量或步骤；
- 增加示范、部分答案或结构提示；
- 形成一次成功后逐步撤掉支架。

## 4. 心流校准

连续表现强且回答含独立思考时，提供保持节奏、增加迁移或深挖边界的选择。连续两次失败时，承认具体难点，只降低一个变量，并给继续、先补基础或暂停的选择。
