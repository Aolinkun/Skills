# 虚构任务卡片示例

以下姓名、日期、数量和路径均为演示占位，不对应真实成员、客户或项目。

## 示例 1：人类分配给 AI

```markdown
> [!task] 任务卡片
> **Who：** 内容助理 Agent
> **When：** 2026-01-15
> **What：** 根据示例素材写 3 条社交媒体短文，每条 300 字以内，风格参考 style-guide.md
> **How to measure：** 3 条短文已保存到 drafts/ 文件夹，每条都包含标题、正文和话题标签
```

## 示例 2：AI 分配给人类

```markdown
> [!task] 任务卡片
> **Who：** 项目成员甲
> **When：** 2026-01-16
> **What：** 联系示例供应商，确认演示项目的交付进度和预计完成时间
> **How to measure：** 进度已记录到 项目跟进.md，包含当前阶段、下一步和预计完成日期
> **备注：** 此任务由协调 Agent 在检查项目记录时创建
```

## 示例 3：已完成任务

```markdown
> [!done] 已完成
> **Who：** 数据整理 Agent
> **When（原计划）：** 2026-01-14
> **When（实际完成）：** 2026-01-14
> **What：** 整理示例项目记录，生成月度汇总表
> **How to measure：** 汇总表已保存到 reports/monthly-summary.md，并覆盖演示数据中的全部记录
> **完成备注：** 发现两条演示记录缺少日期，已标注待确认
```

## 示例 4：AI 调用 AI

```markdown
> [!task] 任务卡片
> **Who：** 分析 Agent
> **When：** 2026-01-15
> **What：** 分析演示项目的渠道分布，给出下月内容策略建议
> **How to measure：** 分析报告已生成，包含渠道占比图表和至少 3 条具体建议
> **备注：** 由协调 Agent 在月度复盘时创建
```
